# Инструкция агенту: `.pre-commit-config.yaml`

- **Что это:** проверки при `git commit` для всех участников: gitleaks, быстрый линт, тесты хуков
- **Когда подхватывается:** перед каждым коммитом, после `uvx pre-commit install` на каждой машине. `doctor.sh` напоминает, если не установлен
- **Действие при переносе:** **подстроить** — правится только блок «Адаптация»

## Что в файле сейчас (проект «DWH-аналитик»)

- `gitleaks` — ищет секреты в том, что попадает в коммит. Сборка хука требует Go, pre-commit ставит его сам.
- `lint` — `uv run ruff check` по изменённым `.py`.
- `test-hooks` — только если менялись `scripts/agent/`, `settings.json` или `.gitignore`.

## Что должно быть в вашем проекте

Только быстрое, секунды на коммит: полные тесты остаются Stop-хуку и CI. Обход `--no-verify` агенту запрещает `guard.sh`.

## Шаги адаптации

1. Замени `lint` на линтер стека (`npx eslint`, `types_or: [ts, tsx]`), добавь форматтер, если он есть.
2. Если в проекте есть файлы с тестовыми секретами, настрой исключения в `.gitleaks.toml`, а не отключай хук.
3. Установи и проверь: `uvx pre-commit install`, `uvx pre-commit run --all-files`.
4. Проверка, что секрет не пройдёт: добавь в индекс файл с поддельным токеном нужного формата, `git commit` должен упасть;
   убери файл. Спроси пользователя перед запуском: команда скачивает и запускает внешний код.
