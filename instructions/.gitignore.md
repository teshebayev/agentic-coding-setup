# Инструкция агенту: `.gitignore`

- **Что это:** фрагмент `.gitignore` только со строками, нужными агентному сетапу
- **Когда подхватывается:** git; Claude Code учитывает `.gitignore` при поиске файлов
- **Действие при переносе:** **подстроить** — каркас общий, поменять команды, пути и примеры под проект

## Что в файле сейчас (проект «DWH-аналитик»)

В нашем полном `.gitignore` агентному сетапу нужны: `/uncommitted-files.md` (рабочий чек-лист команд
`/uncommitted-files`, `/fix-uncommitted`), файлы с доступами и реальными данными (`.env`, `ACCESS.local.md`,
файлы SSH-туннеля, `external/`, `data/`) — ровно те пути, что запрещает `guard.sh`. `.claude/settings.local.json`
у автора игнорируется глобальным git-ignore, здесь строка добавлена явно.

## Что должно быть в вашем проекте

Эти строки внутри вашего существующего `.gitignore`, плюс пути ваших собственных секретов.

## Шаги адаптации

1. Не заменяй `.gitignore` проекта — допиши недостающие строки из фрагмента.
2. Список секретных путей сверь с `secret_path` в `scripts/agent/guard.sh`: что там запрещено читать, то и здесь
   не коммитится.
3. Проверь: `git check-ignore -v .claude/settings.local.json uncommitted-files.md`.
