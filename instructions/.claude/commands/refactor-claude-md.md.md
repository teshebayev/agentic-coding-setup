# Инструкция агенту: `.claude/commands/refactor-claude-md.md`

- **Что это:** слэш-команда `/refactor-claude-md [путь] [--apply]`: аудит CLAUDE.md — что удалить, что перенести в правила, скиллы, хуки, доки
- **Когда подхватывается:** по вызову пользователя; без `--apply` только отчёт
- **Действие при переносе:** **оставить как есть** — файл общий, правка не нужна

## Что в файле сейчас (проект «DWH-аналитик»)

Для каждого пункта CLAUDE.md вопрос «если убрать, Claude начнёт ошибаться?» и решение: удалить / правило с `paths:` / скилл / хук / документ / оставить. Отчёт таблицей + новый текст + «было → стало» по строкам. Читает `docs/README.md`.

## Что должно быть в вашем проекте

То же.

## Шаги адаптации

Скопируй. Если у проекта нет `docs/README.md` — замени в шаге 1 на ваш индекс документации или убери.
