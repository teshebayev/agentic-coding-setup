# Инструкция агенту: `.claude/skills/split-large-tests/SKILL.md`

- **Что это:** скилл: разбить большой файл тестов на тематические без потери ни одного теста
- **Когда подхватывается:** автоматически по описанию (файл тестов 300+ строк, просьба разнести тесты)
- **Действие при переносе:** **подстроить** — каркас общий, поменять команды, пути и примеры под проект

## Что в файле сейчас (проект «DWH-аналитик»)

Снимок `pytest --collect-only` до; план групп по смыслу (100–200 строк на файл); общие фикстуры в `conftest.py`, помощники в `tests/_<тема>_helpers.py`; перенос; снимок после — множество имён тестов совпадает; полный прогон и ruff; итоговая таблица.

## Что должно быть в вашем проекте

Тот же процесс в терминах вашего раннера.

## Шаги адаптации

   имена файлов.
