# Инструкция агенту: `.claude/settings.local.json`

- **Что это:** личные переопределения настроек Claude Code — не коммитятся
- **Когда подхватывается:** при старте сессии, поверх `.claude/settings.json`
- **Действие при переносе:** **заменить своим или удалить** — доменный файл нашего проекта, служит образцом формы

## Что в файле сейчас (проект «DWH-аналитик»)

Одна настройка: `disabledMcpjsonServers: ["dwh-analyst"]` — автор выключил у себя MCP-сервер из `.mcp.json`.

## Что должно быть в вашем проекте

Только личное: выключенные серверы из `.mcp.json`, временно отключённый хук, личные `permissions`, локальный
профиль MCP с боевыми доступами. В репозиторий не попадает.

## Шаги адаптации

1. В архиве файл лежит как пример. В целевой проект его не переносят — либо удали, либо замени имя сервера на
   свой, если пользователь хочет выключить какой-то сервер у себя.
2. Убедись, что путь в `.gitignore` (`git check-ignore -v .claude/settings.local.json`).

## Связи с другими файлами

`.mcp.json`, `.gitignore`.
