# Инструкция агенту: `scripts/agent/doctor.sh`

- **Что это:** SessionStart-хук: проверяет, что защита и процесс сетапа реально работают на этой машине
- **Когда подхватывается:** при запуске новой сессии (`.claude/settings.json`, matcher `startup`). Сессию не блокирует; всё в порядке — молчит; иначе замечания видят и Claude (`additionalContext`), и пользователь (`systemMessage`)
- **Действие при переносе:** **подстроить** — правится только блок «Адаптация»

## Что в файле сейчас (проект «DWH-аналитик»)

- **Адаптация:** `required` (инструменты), `openspec_version`, `min_claude`, `want_plugin`, `secret_files`.
- Проверяет: инструменты хуков; исполняемость скриптов; git-репозиторий; секреты в git или вне `.gitignore`; заданный
  `PYTHONPATH`; версию OpenSpec; версию Claude Code (ниже 2.1.295 не работает `onFailure: block`); включён ли плагин.

## Что должно быть в вашем проекте

Тот же файл с вашими значениями. Проверяйте только то, что сломает сетап и само не проявится; без сети и не дольше пары секунд.

## Шаги адаптации

1. `required` — инструменты ваших хуков и команд (например, `npx` вместо `uv`).
2. `openspec_version` — ваша версия или пустая строка, если OpenSpec не берёте.
3. `want_plugin` — `superpowers` или пустая строка; должно совпадать с ответом пользователя на вопрос о superpowers.
4. `secret_files` — те же файлы, что в `guard.sh`.
5. Проверка: `CLAUDE_PROJECT_DIR=$PWD scripts/agent/doctor.sh` → на настроенной машине пусто; `chmod -x` на скрипт →
   появляется замечание; `chmod +x` обратно.

## Связи с другими файлами

`.claude/settings.json`, `scripts/agent/guard.sh` (`secret_files`), `.superpowers/sdd/.gitignore`, `docs/22-agentic-coding.md` (таблица хуков).
