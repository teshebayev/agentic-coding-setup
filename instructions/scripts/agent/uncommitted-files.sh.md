# Инструкция агенту: `scripts/agent/uncommitted-files.sh`

- **Что это:** скрипт: строит `uncommitted-files.md` — нумерованный чек-лист незакоммиченных файлов из `git status`
- **Когда подхватывается:** вызывается командами `/uncommitted-files` и `/fix-uncommitted`
- **Действие при переносе:** **оставить как есть** — файл общий, правка не нужна

## Что в файле сейчас (проект «DWH-аналитик»)

Берёт `git status --porcelain --untracked-files=all`, сохраняет отметки `[x]` для файлов, которые ещё не закоммичены, удаляет список, если всё закоммичено. Печатает «всего N, осталось M».

## Что должно быть в вашем проекте

То же; от стека не зависит (bash, git, awk, sed).

## Шаги адаптации

1. Скопируй, `chmod +x`.
2. Добавь `/uncommitted-files.md` в `.gitignore`.
3. Проверка: создай временный файл, запусти скрипт — файл появится в списке; удали временный файл.

## Связи с другими файлами

`/uncommitted-files`, `/fix-uncommitted`, `.gitignore`.
