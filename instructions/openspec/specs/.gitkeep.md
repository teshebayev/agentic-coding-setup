# Инструкция агенту: `openspec/specs/.gitkeep`

- **Что это:** заглушка, чтобы пустая папка основных спек попала в git
- **Когда подхватывается:** не грузится
- **Действие при переносе:** **оставить как есть** — файл общий, правка не нужна

## Что в файле сейчас (проект «DWH-аналитик»)

В нашем проекте в `openspec/specs/` уже 5 спек (`file-upload`, `playbook-params`, `stock-reconciliation`, `stock-snapshot`, `uploaded-file-reading`) — в архив сетапа они не включены: это поведение нашего продукта.

## Что должно быть в вашем проекте

Пустая папка в начале; спеки появляются только через `/opsx:archive` (правило `delta-specs.md`).

## Шаги адаптации

Обычно создаётся `openspec init`. Если нет — создай пустой `.gitkeep`. Не наполняй спеки задним числом.
