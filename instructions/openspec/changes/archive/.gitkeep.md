# Инструкция агенту: `openspec/changes/archive/.gitkeep`

- **Что это:** заглушка для папки архива изменений
- **Когда подхватывается:** не грузится
- **Действие при переносе:** **оставить как есть** — файл общий, правка не нужна

## Что в файле сейчас (проект «DWH-аналитик»)

В нашем проекте в архиве два изменения (`2026-10-30-add-file-upload`, `2026-10-31-add-stock-reconciliation`). Одно из них положено в `examples/` архива сетапа как образец полного набора артефактов.

## Что должно быть в вашем проекте

Пустая папка; `/opsx:archive` переносит сюда изменения как `YYYY-MM-DD-<имя>/`. Архив неизменяем.

## Шаги адаптации

Создай пустой `.gitkeep`, если `openspec init` его не сделал. Образец — `examples/`, в `openspec/` его не копируй.

## Связи с другими файлами

`process-invariants.md`, `guard.sh` (запрет правки архива).
