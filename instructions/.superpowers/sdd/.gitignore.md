# Инструкция агенту: `.superpowers/sdd/.gitignore`

- **Что это:** служебная папка плагина superpowers: скилл subagent-driven-development складывает сюда промежуточные файлы
- **Когда подхватывается:** плагином superpowers при работе субагентов; `*` внутри — ничего из папки не коммитится
- **Действие при переносе:** **оставить как есть** — файл общий, правка не нужна

## Что в файле сейчас (проект «DWH-аналитик»)

Одна строка `*`. Сам плагин стоит на уровне пользователя, не в репозитории:
`~/.claude/settings.json` → `"enabledPlugins": {"superpowers@anthropic-plugin-directory": true}`. Из superpowers в
этом процессе используются TDD, systematic-debugging, verification-before-completion (внутри `/opsx:apply`);
его brainstorming и writing-plans заменены OpenSpec.

## Что должно быть в вашем проекте

Тот же файл, если пользователь ставит superpowers; иначе папка не нужна.

## Шаги адаптации

1. Спроси, установлен ли superpowers (`/plugin` в Claude Code). Если нет — предложи установить (`/plugin install
   superpowers@...` из каталога плагинов) или удали папку и упоминания superpowers в `CLAUDE.md`,
   `openspec/config.yaml`, `docs/22-agentic-coding.md`.
2. Если да — скопируй файл как есть.
