# Глоссарий разработки харнесса «DWH-аналитик»

Термины, которыми говорим о харнессе и его возможностях. Бизнес-термины склада и DWH (остаток, SKU, позиция,
заявка, отгрузка, клиент) — в [dwh-knowledge/conventions.md](dwh-knowledge/conventions.md), здесь их не копируем.

## Файлы пользователя

**Загруженный файл**:
Файл, который пользователь передал харнессу в рамках беседы; харнесс хранит его и превращает в таблицу или текст,
с которыми работает модель.
_Избегать_: вложение, аттачмент, документ (документ — это документ WMS: заявка, отгрузка, приёмка)

**Сверка остатков**:
Сравнение остатков по SKU из загруженного файла клиента с остатками в DWH на ту же дату.
_Избегать_: сверка (без уточнения — слово занято проверкой ответа и сверкой заявок с фактом), дифф, reconciliation

**Расхождение**:
SKU, у которого при сверке остатков количество в файле клиента не совпало с DWH или который нашёлся только
на одной стороне.
_Избегать_: ошибка, несоответствие, проблемная строка
